# 🌤️ Weather Dashboard

A responsive web application that provides real-time weather updates, multi-day forecasts, and detailed atmospheric metrics for cities around the globe.

## 🚀 Features

- **Current Weather:** View real-time temperature, weather conditions, humidity, wind speed, and pressure.
- **City Search:** Look up weather conditions for any location worldwide.
- **Multi-Day Forecast:** Get weather projections for upcoming days to plan ahead.
- **Responsive Interface:** Formatted for desktop, tablet, and mobile devices.

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **API:** [OpenWeatherMap API](https://openweathermap.org/api) (or equivalent weather data provider)
